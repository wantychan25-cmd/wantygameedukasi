📚 Materi Sistem Operasi (4 Pertemuan)

Pertemuan 1: Konsep Dasar Sistem Operasi

Pengertian: Sistem Operasi (OS) adalah perangkat lunak sistem yang mengelola perangkat keras (hardware) dan perangkat lunak (software), serta menjembatani interaksi pengguna dengan komputer.

Fungsi Utama OS:

  • Resource Manager: Mengelola memori, prosesor, dan perangkat I/O.
  • Manajemen File: Mengatur struktur dan keamanan data.
  • User Interface: Menyediakan antarmuka (GUI/CLI) untuk pengguna.
  • Manajemen Proses: Mengatur aplikasi yang berjalan (multitasking).

Istilah Penting:

  • Kernel: Inti dari sistem operasi.
  • GUI (Graphical User Interface): Antarmuka grafis (ikon, jendela).
  • CLI (Command Line Interface): Antarmuka berbasis teks/perintah.

Pertemuan 2: Sistem Operasi Jaringan & Open Source

OS Jaringan: OS yang dirancang khusus untuk mengelola jaringan komputer, server, dan layanan jaringan (contoh: Windows Server, Linux Ubuntu Server).

Open Source vs Closed Source:

  • Open Source: Kode sumber terbuka, gratis, bisa dimodifikasi (Contoh: Linux, Ubuntu, Debian).
  • Closed Source: Kode sumber tertutup, berbayar/berlisensi, tidak bisa dimodifikasi sembarangan (Contoh: Windows, macOS).

Lisensi:

GNU/GPL adalah lisensi populer untuk software open source yang mengizinkan penggunaan, modifikasi, dan distribusi ulang secara bebas.

Pertemuan 3: Instalasi Sistem Operasi

Proses pemasangan OS ke dalam hardisk komputer agar dapat digunakan.

Langkah-langkah Instalasi:

  • Setting BIOS/UEFI: Mengatur Boot Priority agar komputer booting dari Flashdisk/CD.
  • Partisi Hardisk: Membagi hardisk menjadi beberapa bagian (Primary, Extended, Logical).
  • Formatting: Memberi sistem file pada partisi (NTFS untuk Windows, ext4 untuk Linux).
  • Copying File & Instalasi: Proses penyalinan file OS dan konfigurasi awal.

Catatan: Di Linux, terdapat partisi khusus bernama Swap yang berfungsi sebagai RAM cadangan.

Pertemuan 4: Konfigurasi Dasar & Manajemen File

Mengenal perintah dasar untuk mengelola file dan folder melalui CLI (Command Line Interface).

Perintah Dasar Windows (CMD):

  • cd: Pindah direktori.
  • dir: Melihat isi folder.
  • md / mkdir: Membuat folder.
  • del: Menghapus file.
  • copy: Menyalin file.

Perintah Dasar Linux (Terminal):

  • ls: Melihat isi direktori.
  • pwd: Melihat posisi direktori saat ini.
  • rm: Menghapus file.
  • cat: Melihat isi file teks.
  • sudo: Menjalankan perintah dengan hak akses administrator (root).
